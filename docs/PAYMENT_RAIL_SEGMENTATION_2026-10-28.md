# 予約の事前決済と現地決済を混同しない：MF連携・照合対象の分岐（2026-10-28）

## 今回の新しい公式根拠

1. **STORES 決済 → MFクラウドは自動連携がある。** STORES 決済公式FAQ（**2026-10-02更新**）は、STORES 決済のクレジット売上額をMFクラウドへ自動計上する連携手順を案内。2025-09-18以降の請求書決済には一部対象制限がある。**これはSTORES 予約の事前決済の自動連携を保証しない。** https://support.coiney.com/hc/ja/articles/115007912688
2. **STORES レジで現地決済を処理すると、予約と会計が連動する条件がある。** STORES 予約公式FAQ（**2026-07-22更新**）では、レジの「予約」タブから会計しないと予約情報に反映されない。また「入金待ち」のオーダーは、**決済失敗の可能性があってもレジの販売実績には計上される**一方、決済方法別実績には計上されず、予約の決済済み表示もされない。既存の会計済みオーダーを後から予約に紐付けることはできない。https://reserve-faq.stores.jp/hc/ja/articles/53034030789913
3. **STORES 予約の支払方法は4種。** STORES 予約公式FAQ（**2026-02-03更新**）は、①予約時カード事前決済、②回数券、③月謝、④現地払いを区別。現地払いはSTORES 予約上では決済しない。https://reserve-faq.stores.jp/hc/ja/articles/28701429334297

既存の公式根拠：STORES予約はMF/freeeへの自動連携非対応（2025-11-14更新） https://reserve-faq.stores.jp/hc/ja/articles/52258293899673 。STORES予約の入金内訳には予約と回数券・月謝の別ファイルがある https://reserve-faq.stores.jp/hc/ja/articles/28713301405977 。
