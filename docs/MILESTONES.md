### 進捗台帳の自動再判定（2026-10-28追加）

`npm run milestones` は `docs/demand-evidence.json` を**唯一の証拠集計元**として読み直し、日本時間の当日で期限超過を**表示上** `overdue` と判定する。期限当日は超過扱いせず、翌日から `blocked` も `overdue` にする。実際の証拠数と `docs/milestones.json` のスナップショットの差分、次の未達期限、商用化No-Go/人間審査待ちを表示する。

```sh
npm run demand
npm run milestones
npm run milestones -- --as-of 2026-11-08  # 過去・将来の日付で再現
npm run milestones -- --write            # 差分があるときだけJSON台帳を同期
npm test
```

`--write` は**JSON台帳のみ**を更新し、Markdown表は実行日時点の記録として維持する。書き込み後は差分をレビューし、GitHubにコミットすること。コマンドの起動やGitHubへのコミットは自動スケジュール化していないため、定期作業時に実行する。数値が揃っても `done` を自動付与せず、M4・M5の必須証拠不足なのに `done` と記録した場合はエラーにする。実CSV適合は**未検証**のまま。検証コード: `tests/milestone-progress.test.mjs`。
