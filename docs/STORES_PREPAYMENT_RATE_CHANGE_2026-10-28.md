# STORES予約の2026年8月3日決済手数料改定と月次照合・価格仮説（2026-10-28）

> 対象: Issue #3（有料需要）・#2（実CSV適合）。**公式仕様の確認**であり、利用者の体験談・支払意思・実CSV適合を示すものではない。第三者への営業送信、実顧客データ取得、決済、公開デプロイは行っていない。

## 公式に確認できた重要な変化

- **2026-08-03 00:00以降の事前カード決済**は、従来の **4.9%＋決済ごと99円**から、STORESパッケージプランと中小特別料率の組合せで決まる料率へ変更された。現在のFAQ（2026-08-02更新）は**決済ごとの固定額なし**と明記。**STORES予約の「スモール/チーム/ビジネス」等の有料プランと、STORESパッケージの「スタンダード」は別契約**。
- 事前カード決済の対象は**予約時決済だけでなく、月謝集金・回数券販売**を含む。銀行入金を説明するには予約一覧だけでは不足する可能性がある（既存の入金内訳2種類の調査と整合）。
- 料率はフリー通常 **5.5%**、フリー中小特別 **5.2%**、スタンダード通常 **3.6%**、スタンダード中小特別 **3.3%**。中小特別料率は自動適用ではなく**申請と認可**が必要。**決済日・契約状態・承認状態**が未確認なら、売上額から手数料を逆算して「一致」と判定できない。
- 旧料率と新料率の損益分岐は決済単価 **16,500円**（STORES公式の説明）。固定99円の廃止で低単価ほど新フリー通常料率が有利だが、実CSVに旧料率・新料率の期間が混在し得る。
- STORES予約の**売上分析**にある「入金額」は売上から**決済手数料**を差し引く指標として定義されている。一方、**2026-08-25以降の振込**には別途275円等の振込手数料が発生するため、分析上の「入金額」を銀行通帳の実着金と常に同額と決め打ちしない。画面・期間・確定/予定状態・控除済み項目を実資料で確認する。

## 価格と既存代替策の反証（Issue #3）

STORESスタンダードは年契約で月額 **3,300円（税込）**、月契約 **3,960円（税込）**。フリーからスタンダードへの料率差は通常・特別とも **1.9ポイント**。**他のプラン特典を無視**して決済手数料差だけで年契約の月額3,300円を回収する仮定なら、月の対象事前決済額は **3,300 / 0.019 ≒ 173,684円** が目安（実測値ではない）。この既存の選択肢は月額2,980円という独自ツール価格仮説と同じ事業者の予算を取り合う可能性がある。ただしスタンダードはCSV入金照合ツールの代替機能を直接保証しない。

**反証すべき仮説**: スタンダード等の既存プラン、MF会計の銀行連携・重複チェック、Excelを使った**後**にも、事前カード決済・月謝・回数券の確定入金差額説明が月90分程度以上残るか。月額2,980円の購入意思は未確認。

## 実CSV受入条件への追加（Issue #2）

1. **決済日**が2026-08-03の改定境界の前後どちらか、同じ振込に旧/新料率が混在するかを確認する。
2. **取引当時**のSTORESパッケージ（フリー/スタンダード）と中小特別料率の**申請・認可・適用日**を別に確認する。予約プラン名から推定しない。
3. 予約時決済、月謝、回数券を別の出力元から確認し、各々の手数料・返金・振込への帰属と二重計上を検証する。識別子・ヘッダー・丸め・控除位置は実サンプルで確認するまで**未確定**。
4. 売上分析の「入金額」、確定入金履歴、振込/事務手数料、銀行実着金を**別フィールド/別資料**として照合し、振込手数料を二重控除しない。
5. MFの税区分・取引No・仕訳インポート仕様は別途検証し、推測で本番投入可能と宣伝しない。
