# 検証計画（2026-10-26）

## 確認した事実

- STORES予約は予約一覧のCSV書き出しを提供している。
- STORES予約の公開FAQでは、freee／マネーフォワード会計への直接自動連携には未対応と説明されている。
- マネーフォワード会計の仕訳帳はCSVの公式サンプル書式を指定し、取り込むたびに新規仕訳が登録される。

## 未確認

- STORES予約の実際の出力CSVヘッダーと決済情報の保持形態。
- 同じ予約IDに複数の決済や返金が紐づく場合の識別子。
- 予約日・決済日のどちらで仕訳すべきか（会計方針に依存）。
- サービス提供者がCSV照合に毎月いくら支払うか。

## 現場ヒアリング（5人）

1. 毎月どのCSVを誰が何分かけて加工していますか？
2. 会計ソフトへインポートするまでにどんな手作業が必要ですか？
3. キャンセル、返金、前受金、手数料をどう照合していますか？
4. 差額や二重計上が起きたときどう発見しますか？
5. この作業を正確に短縮できればいくら支払いますか？

## Go / No-go

- 有料トライアルの意思が3人以上 → 実CSV適合と安全性改善へ進む。
- 無償利用のみ → 価格と必要機能を見直す。
- 明確な困りごとがない → 隣接領域へ方向転換。

## 公開前の条件

- 実CSVサンプルは本人の同意を得たうえで匿名化し、公開GitHubへ追加しない。
- 会計の正確性、税区分、仕訳計上時点は専門家と確認。
- 実務利用・デプロイ・課金・集客は別フェーズとして判断。
